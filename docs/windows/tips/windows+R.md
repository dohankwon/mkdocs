# Windows 10 실행키 입력 명령어 모음

## 시스템 도구 관련 명령어

| 명령어         | 설명                |
| -------------- | ------------------- |
| compmgmt.msc   | 컴퓨터 관리         |
| devmgmt.msc    | 장치 관리자         |
| diskmgmt.msc   | 디스크 관리         |
| lusrmgr.msc    | 로컬 사용자 및 그룹 |
| fgsmgmt.msc    | 공유 폴더           |
| certmgr.msc    | 인증서 관리         |
| eventvwr(.msc) | 이벤트 뷰어         |
| perfmon.msc    | 성능 모니터         |
| services.msc   | 서비스              |
| comexp.msc     | 구성 요소 서비스    |
| sf.msc         | 방화벽 고급 설정    |
| taskschd.msc   | 작업 스케줄러       |
| tsconfig.msc   | 터미널 관리         |
